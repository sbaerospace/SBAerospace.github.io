Hardware and flight software

CAD + flight code

ARC airbrake system (2025–26)

An airbrake module for the 2025–26 American Rocketry Challenge rocket. Four flaps fold out of a 3D-printed airframe section to add drag, so the rocket can be slowed toward the 750 ft target altitude.

  • Version 2 CAD covers the airbrake chassis, flaps, flap joints, fin can, and electronics-bay centering ring, saved as 3D-print files.
  • A servo moves the flaps, controlled by the Rocket++ flight code.

Software

Rocket++ airbrake flight code

C++ flight code for the airbrake system, written for an Arduino-compatible board. It reads a BME280 barometric sensor and an MPU6050 accelerometer, predicts apogee during flight, and decides when to deploy the brakes to reach 750 ft (228.6 m).

  • The screenshot shows an early version; mass and drag constants are set for each rocket.

Prototype

NDVI vegetation-mapping payload (NASA TechRise)

Our NASA TechRise payload measures how much visible and near-infrared light the ground reflects. Those readings are used to calculate NDVI, a common measure of plant health.

  • Sensors: AS7343 spectral sensor (visible and near-infrared channels), TSL2591 light sensor, BME280, and MPU6050.
  • Records World View balloon telemetry and sensor readings to an SD card once per second.
  • Python flight software keeps logging if a sensor fails and shows status on LEDs.

Flown

ARC competition rockets

Each season, a club team designs and builds a rocket for the American Rocketry Challenge. The rocket has to carry a raw egg, hit set altitude and flight-time targets, and bring the egg back uncracked.

  • 2024 and 2025: flown at the National Finals.
  • Photo: SBHS students’ ARC build on the pad at the World Space Week launch at North Branch Park, October 2026.

Simulation and design tools

Simulation

Airbrake CFD study

A computational fluid dynamics (CFD) comparison of airflow around the rocket without airbrake flaps (top) and with the flaps extended (bottom). These are simulation results, not flight measurements.

Web tool

CircuitSpace

A browser-based planner for rocket electronics. Members place batteries, switches, flight computers, and servos and connect them; the tool checks the wiring, lists the parts, estimates mass, and exports diagrams as SVG.

Simulation

OpenRocket flight simulation

Before building, teams model their rockets in OpenRocket to check stability and predict altitude and flight time against the ARC targets. Tryout applicants for simulation roles practice the same process.
